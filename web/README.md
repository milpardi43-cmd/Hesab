# حسابیار — نسخه نمایشی مرورگر

این پوشه یک اپلیکیشن تک‌صفحه‌ای (SPA) کاملاً استاتیک است که برای نمایش قابلیت‌های حسابیار در مرورگر ساخته شده است. هیچ بک‌اند، دیتابیس یا سرویس خارجی لازم ندارد و همه داده‌های نمونه در `localStorage` مرورگر نگه‌داری می‌شوند.

## اجرا

```bash
python3 -m http.server 3000 --directory site
# سپس http://localhost:3000
```

یا هر وب‌سرور استاتیک دیگر؛ کافی است پوشه `site` را به‌عنوان ریشه سرو کنید.

## ساختار

```
site/
├── index.html            پوسته اپ، آیکون‌ها، ناوبری
├── styles.css            سیستم طراحی، چیدمان واکنش‌گرا و RTL
├── js/
│   ├── app.js            مسیریابی hash، مودال‌ها، رویدادها و فرم‌ها
│   ├── views.js          قالب صفحه‌ها و نمودارهای SVG
│   ├── store.js          داده نمونه، عملیات حسابداری و localStorage
│   ├── format.js         اعداد، تومان، تقویم جلالی و ورودی مبلغ
│   └── icons.js          آیکون‌های SVG
├── assets/fonts/         وزیرمتن
└── manus-routes.json     مانیفست مسیرها
```

## قابلیت‌های نمایشی

داشبورد، فروش (نقدی/نسیه/ترکیبی)، خرید با کرایه و میانگین بهای تمام‌شده، هزینه، کالا و انبار، اشخاص و مانده حساب، حساب‌ها و انتقال وجه، گزارش‌های روزانه/ماهانه، یادآوری‌ها و تنظیمات. ثبت فروش، موجودی، مانده حساب‌ها و تراکنش‌ها را در همان مرورگر به‌روز می‌کند.

برای بازگردانی داده‌های اولیه از «تنظیمات → بازنشانی داده‌های نمونه» استفاده کنید. پشتیبان JSON نیز از همان صفحه قابل دانلود و بازیابی است.

## تفاوت با نسخه اندروید

این نسخه برای نمایش سریع و بررسی تجربه کاربری است؛ منطق حسابداری آن ساده‌شده و در جاوااسکریپت پیاده‌سازی شده و به Room متصل نیست. نسخه اندروید (پوشه `hesabyar-android`) موتور حسابداری، دیتابیس Room، تراکنش‌های اتمیک، پشتیبان‌گیری و تست‌های واقعی دارد.
